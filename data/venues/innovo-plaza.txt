# Innovo Plaza, Duitama, Boyaca

# Este archivo se llena a mano caminando el mall. Es a proposito: OpenStreetMap
# tiene 467 comercios mapeados en Duitama y solo 1 adentro de este mall, asi que
# el problema de interiores es doble, no hay GPS util y tampoco hay datos de POI.
#
# NO hace falta coordenada por local. Adentro del edificio el error horizontal
# supera la distancia entre locales, asi que darle lat/lon a cada tienda seria
# declarar una precision que no existe. El mall tiene una coordenada y todos sus
# locales entran juntos como candidatos.
#
# Como llenarlo: un local por linea, con el formato
#
#     Nombre del local | categoria
#
# Vocabulario de categorias (usa la que mas se acerque):
#
#   comida        restaurante  comida-rapida  cafe  bar  heladeria  panaderia
#                 dulces  carniceria  supermercado  tienda  fruteria
#   ropa          ropa  ropa-deportiva  zapatos  marroquineria  joyeria
#                 relojeria  cosmeticos  perfumeria
#   tecnologia    electronica  celulares  electrodomesticos  musica  discos
#                 fotografia
#   ocio          libreria  papeleria  juguetes  videojuegos  regalos  deportes
#                 cine  gimnasio  mascotas
#   servicios     farmacia  optica  peluqueria  barberia  spa  lavanderia
#                 floristeria
#   hogar         muebles  ferreteria  materiales
#   general       variedades  departamental  descuento  mayorista  general
#
# Si no sabes la categoria de un local, escribi ? y el script te avisa cuantos
# quedaron sin clasificar. Es mejor eso que adivinar el MCC.
#
# Cuando termines:  npm run venue --workspace=@yapa/seed -- innovo-plaza
